연습장 HUD 를 롤처럼: [초상화][Q W E R][D F] — 구현 계획서
작성 2026-10-01 · 대상 브랜치: champ-spell-anims 위(또는 main 에 합친 뒤 새 브랜치)

────────────────────────────────────────
0. 목표와 범위
────────────────────────────────────────
- 이번 단계: 스킬 칸 네 개(Q W E R)를 HUD 에 "칸으로만" 만든다. 아이콘·키·쿨타임 표시까지.
  실제 스킬 기능(이즈리얼 E 순간이동 등)은 다음 단계. 기능이 없는 칸은 롤의 "못 씀" 처럼 어둡게.
- 나중 목표: 내 챔피언을 골라 그 챔피언의 이동기(바로 쓰는 돌진·순간이동)로 피하기.
  3D 동작은 이미 준비됨 → tools/champ_models.py 의 MOBILITY(40명, 챔피언 → 스킬 번호 1~4),
  모델에는 spell1~4 이름으로 구워져 있다(static/dodge/models/index.json 의 anims 로 확인 가능).
- 화면 배치(롤 기본 HUD):
    [ 초상화+레벨 ] [ Q ][ W ][ E ][ R ] [ D ][ F ]
                    [ ─────── 체력바 ─────── ]
  스킬 칸이 주문 칸보다 조금 크다(롤 비율 대략 스킬 1 : 주문 0.8).

────────────────────────────────────────
1. 키 배치 (사용자가 정함)
────────────────────────────────────────
                 Q          W          E     R     주문1  주문2
  마우스 클릭    Q          W          E     R     D      F
  WASD           마우스 우클릭  왼쪽 Shift  E     R     V      F

- WASD 방식에서 W 는 이동 키라서 스킬은 우클릭·Shift 로 옮긴다.
- 주문 키는 지금과 같다(keyPair: 마우스 D·F, WASD V·F). 바꿀 것 없음.
- 휴대폰: 칸을 눌러 쓴다(지금 주문 칸과 같은 방식).
- 칸의 키 표시(kbd): 우클릭은 그림 문자 대신 "우클릭" 짧은 글씨나 마우스 아이콘, Shift 는 "Shift".

────────────────────────────────────────
2. 지금 코드에서 손댈 곳 (static/dodge.js, static/app.css)
────────────────────────────────────────
(줄 번호는 2026-10-01 기준. 바뀌었으면 이름으로 찾기)

a) 조작 설정 (dodge.js 위쪽, 65~85줄 부근)
   - keyPair(move) 옆에 skillKeys(move) 추가:
       mouse → ["KeyQ","KeyW","KeyE","KeyR"]
       wasd  → ["Mouse2","ShiftLeft","KeyE","KeyR"]     (Mouse2 = 우클릭, 내가 정한 가짜 코드)
     화면 표시용 글자는 따로: mouse → Q W E R, wasd → 우클릭 Shift E R
   - controls(localStorage "tiergg-dodge-controls") 는 그대로 둔다. 새 저장값 필요 없음.

b) HUD 마크업 (mount 안, 556줄 부근 .lol-hud)
   - .lol-main 안 .lol-spells 앞에 .lol-skills 를 넣는다:
       <div class="lol-skills">
         ${[0,1,2,3].map(i => `<button type="button" class="lol-skill" data-skill="${i}">
             <img alt=""><i></i><b></b><kbd></kbd></button>`).join("")}
       </div>
     <i> = 쿨타임 부채꼴, <b> = 남은 초, <kbd> = 키. 주문 칸(.lol-spell)과 같은 구조로 맞춰
     paintSpells 의 쿨타임 그리기 코드를 함수로 빼서 같이 쓴다.
   - .lol-skills 와 .lol-spells 를 한 줄(flex)로, 그 아래 체력바.

c) 칸 그리기 (paintSpells, 2816줄 부근 / 쿨타임 갱신 2802줄 부근)
   - paintSkills() 새로: 아이콘·키 글자·못 씀 표시. 판 시작(start)·조작 바꿈·챔피언 바꿈(setChamp) 때 부른다.
   - 기능 없는 칸: class="off" → 회색(filter: grayscale(1) brightness(.5)), 누르면 아무 일 없음.
   - 쿨타임 부채꼴은 주문 칸과 같은 함수로(이번 단계에선 늘 0).

d) 입력 (onKeyDown 2923줄 부근, onPointerDown 2907줄 부근)
   - onKeyDown: 스킬 키(e.code 가 skillKeys 에 있음) → useSkill(i). 이동 키보다 먼저 검사.
     주의: WASD 에서 KeyE·KeyR 는 이동 키가 아니라 겹치지 않음. ShiftLeft 는 e.code === "ShiftLeft".
     e.repeat 은 무시(주문과 같게).
   - onPointerDown: controls.move === "wasd" && e.pointerType === "mouse" 일 때
     e.button === 2 → useSkill(0)(Q), 그 밖의 버튼은 지금처럼 cursor 만 갱신.
     우클릭 방향은 cursor = toArena(e) 를 먼저 갱신한 뒤 쓴다(스킬이 커서 쪽으로 나가야 하니까).
   - 칸 누르기: [data-skill] 에 pointerdown → useSkill(i) (주문 칸 2950줄 부근과 같게).
   - useSkill(i): 이번 단계에선 칸이 off 면 아무것도 안 함. 다음 단계에서 MOBILITY 기능 연결.

e) 시작 창(조작 고르는 창, 2975줄 부근)
   - 키 설명 줄에 스킬 키도 보여 준다: 마우스 "Q W E R 스킬 · D F 주문", WASD "우클릭 Shift E R 스킬 · V F 주문".

f) CSS (app.css 847줄 부근 .lol-hud ~ .lol-spell)
   - .lol-skill: .lol-spell 과 같은 꾸밈, 크기만 calc(var(--u) * 52) 정도(주문 칸은 지금 값 유지).
   - .lol-skill.off img { filter: grayscale(1) brightness(.45); }  커서 기본(default).
   - 휴대폰(stage 폭 600 미만)에서는 HUD 가 커지니 칸 사이 간격을 줄이고, 넘치면 체력바를 칸 아래로.
     fit() 의 HUD_ROOM(0.12 / 휴대폰 0.2) 이 HUD 높이를 감당하는지 확인, 모자라면 올린다.

────────────────────────────────────────
3. 스킬 아이콘 받기
────────────────────────────────────────
- 초상화가 쓰는 것과 같은 CommunityDragon(CORS 됨):
    plugins/rcp-be-lol-game-data/global/default/v1/champions/{챔피언 ID}.json
  의 spells[] (spellKey "q" "w" "e" "r", abilityIconPath) 를 쓴다.
  abilityIconPath 가 "/lol-game-data/assets/ASSETS/..." 꼴이면
    CDRAGON + "plugins/rcp-be-lol-game-data/global/default/" + 뒤쪽(assets/ 부터, 소문자)
  로 바꾼다. ← 실제 응답으로 경로 규칙을 먼저 확인할 것(추정임).
- 챔피언 ID 는 이미 있는 CHAMP_IDS(loadChampIds, 270줄 부근) 를 쓴다.
- 챔피언마다 한 번만 받아 Map 에 담는다. 못 받으면 칸은 빈 테두리 + 글자(Q W E R) 로.
- HUD 는 DOM 이라 CORS 걱정 없음(캔버스에 안 그림).

────────────────────────────────────────
4. 확인할 것 (완료 기준)
────────────────────────────────────────
- 마우스 방식: Q W E R 칸에 키 Q W E R, D F 주문이 그대로 동작.
- WASD 방식: 칸에 "우클릭 Shift E R" 표시. 우클릭이 이동을 일으키지 않고, W 는 여전히 위로 이동.
  Shift·E·R·우클릭을 눌러도 오류 없음(지금은 off 라 아무 일 없음).
- 하드 모드(정화 칸) · 노멀 모드 둘 다 주문 칸 정상.
- 내 챔피언 바꿈(setChamp) 때 아이콘이 그 챔피언 것으로 바뀜(이즈리얼 → 다른 OP 챔피언).
- 휴대폰 폭(390px) 에서 HUD 가 경기장을 가리지 않고, 칸을 누르면 반응.
- 확인 방법: static 폴더에서 python -m http.server 로 띄우고, DodgeGame.mount(div, { champ: "Lucian" })
  만 부르는 임시 html(지난번 _harness.html 처럼) 로 보면 서버(DB) 없이 된다. 임시 파일은 커밋 전에 지운다.

5. 다음 단계(이번 범위 밖) 메모
────────────────────────────────────────

  돌진(루시안 E, 베인 Q, 그레이브즈 E, 그라가스 E …), 각 사거리·쿨타임은 롤 데이터에서(적 스킬처럼 대조).

- MOBILITY 목록은 롤 지식으로 고른 것이라 롤 데이터와 한 번 대조할 것.
