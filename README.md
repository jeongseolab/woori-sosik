# Tier.gg — 내 챔피언만으로 만드는 티어표

FastAPI 로 만든 롤 전적 서비스. 데이터는 OP.GG 가 공개한 MCP 서버에서 받는다.

- **나만의 티어표** — 최근 20판(솔로랭크·자유랭크·일반)에서 고른 챔피언을
  내 승률·KDA·판수와 내 티어 구간의 메타로 줄 세운다. OP 는 딱 한 명, 나머지는 1~5티어에 나눈다.
- **그룹방** — 방을 만들면 6글자 초대 코드가 나온다. 들어온 친구들끼리
  랭크·승률·KDA·분당 CS·OP 챔피언을 나란히 비교하고, 서로의 티어표를 본다.
- **듀오 궁합** — 두 사람의 경기에서 같은 판을 찾아 같이 할 때 승률,
  평소 승률, 잘 맞은 챔피언 조합, 맞대결 전적을 정리한다.
- **주간 랭킹** — 그룹방에서 이번 주(월요일 0시, 한국 시각부터) 종합 순위를 보여 준다.
  플레이 점수 50% + 승률 25% + KDA 25%, 셋 다 50점이 보통인 잣대로 바꿔 섞음. 이번 주 3판 이상.
  스킬샷 피하기 순위는 그룹방의 "무빙 순위" 탭에 따로 있다.
- **연습장: 스킬샷 피하기** — 사방에서 날아오는 논타깃 스킬을 피해 버티는 게임.
  그룹방 "무빙 순위" 탭에 최고 기록 순위가 나오고, 거기서 바로 도전하러 갈 수 있다.
  연습장의 "무빙 순위" 버튼은 마지막으로 본 방의 무빙 순위 탭으로 바로 간다.

## 스킬샷 피하기 (`static/dodge.js`)

서버 없이 화면 코드만으로 돈다. `index.html` 이 처음부터 같이 받아 두므로 누르면 바로 뜬다.

롤 인터페이스를 흉내 낸 오프라인 연습 모드 느낌으로 만든다.
- 아래 가운데 HUD: 내 챔피언 초상화(티어표의 OP 챔피언, 없으면 이즈리얼)와 레벨, 소환사 주문 두 칸(쿨타임이
  시계 방향으로 걷힌다), 세 칸으로 나뉜 체력(1500, 한 번 맞을 때 500). 위 가운데 시계, 오른쪽 위 피한 수·맞은 수,
  오른쪽 아래 미니맵(휴대폰은 숨김). 아래 HUD 가 경기장을 가리지 않게 그만큼 아래를 비워 둔다
- 머리 위 체력바: 나는 초록(레벨·이름), 적은 빨강(챔피언 이름). 맞으면 피해 숫자가 떠오른다
- 안내 문구: 시작할 때 "소환사의 협곡에 오신 것을 환영합니다", 30초마다 생존, 피한 수 20·40·60·80 에
  "학살 중입니다!" 같은 연속 처치 문구, 한 칸 남으면 "체력이 낮습니다"(가장자리가 붉게 숨 쉰다),
  죽으면 화면이 회색으로 바뀌고 "처치당했습니다" 뒤에 결과 창
- 시작 전에 이동 방식과 주문 배치를 고른다(브라우저에 기억, 결과 창의 "조작 바꾸기" 로 다시 고름).
  마우스 클릭이면 우클릭 이동에 주문 키 D/F(WASD 이동은 꺼짐), WASD 면 키보드 이동에 주문 키 V/F
  (마우스 클릭 이동은 꺼지고 커서는 점멸 방향만). 점멸을 두 키 중 어느 쪽에 둘지도 고른다. 휴대폰 터치 이동은 늘 된다
- 소환사 주문: 점멸(커서 쪽으로 400, 커서를 모르면 가던 방향), 유체화(3초 동안 이동 속도 +40%).
  휴대폰은 HUD 의 칸을 누른다.
  아이콘과 실제 쿨타임(300초·240초) 은 롤 데이터, 점멸 거리·유체화 이속은 롤 위키. 쿨타임(15·20초) 과
  유체화 지속 시간은 이 게임에 맞게 줄였다
- 레벨은 8초마다 하나(18까지). 효과음은 파일 없이 WebAudio 로 만들고 끌 수 있다(브라우저에 기억)
- 바닥은 협곡 느낌 질감(풀밭·돌길·강·가장자리 수풀) 을 한 번 만들어 원근에 맞게 가로 띠로 깐다

화면은 유사 3D 다. 판정과 움직임은 모두 바닥(2D) 에서 하고, 그릴 때만 롤 기본 카메라처럼 56° 비스듬히 내려다보는
원근으로 옮긴다(`proj`). 우클릭한 화면 위치는 거꾸로 바닥 좌표로 되돌린다(`unproj`).
캐릭터·적 초상화·투사체는 화면에서 똑바로 세우고(`upright`), 감옥 창살·빛기둥은 원근을 따른다.
투사체는 공중에 떠서 날지만 바닥에 보이는 그림자 원이 실제 판정이다. 내 발밑 초록 링(65) 과 이 원이 겹치면 맞는다.
투사체의 밝게 꽉 찬 부분은 판정 크기와 같고, 바깥 빛번짐은 옅게만 둔다.
생김새는 스킬마다 다르다(`look`): 자이라 E 는 바닥을 기는 덩굴, 블리츠·쓰레쉬 Q 는 사슬 달린 갈고리, 니달리 Q 는 창,
애쉬 R 은 얼음 화살, 징크스 W 는 전격, 레오나 E 는 칼날, 아리 E 는 하트, 이즈리얼 Q 는 광탄, 브랜드 Q 는 불티 날리는 화염구.
판정은 모두 머리 쪽 원 하나다. 제라스 W·레오나 R 은 데이터의 중심부(100·120) 를 안쪽 점선 원으로 보여 준다(맞는 범위는 바깥 원)
효과(빛나는 투사체와 꼬리, 장판이 터질 때 빛기둥·고리·파편, 레이저 섬광, 맞을 때 흔들림과 붉은 테두리) 는 그림일 뿐 판정과 상관없다.

- 거리·속도는 롤 게임 단위 그대로다. 내 챔피언은 판정 반지름 65(데이터에 따로 없는 챔피언의 기본값.
  블리츠·초가스는 80, 베이가는 55), 이동 속도 335(챔피언 기본 이동 속도 `baseMoveSpeed` 325~345 의 가운데 값)
- 어떤 스킬이 나올지: 그때까지 열린 스킬(`from` 초부터) 중에서 똑같은 확률로 고른다. 그래서 초반엔 5개가 20% 씩,
  50초 뒤엔 24개가 4% 씩이다. 가끔 스킬(애쉬 R·럭스 R) 은 둘을 합쳐 3%. 감옥은 한 번에 하나만
- 목숨 3개. 3번 맞으면 끝이고 버틴 시간이 기록이다. 맞은 뒤 1초는 무적(스킬 두 개에 한꺼번에 목숨 둘을 잃지 않게).
  스킬 하나는 한 번만 때린다(맞힌 투사체는 사라지고, 감옥은 한 번 스턴하면 끝)
- 스킬 26개, 네 종류:
  - 투사체 15개: 모르가나 Q, 럭스 Q, 자이라 E, 니달리 Q, 브랜드 Q, 아리 E, 벨코즈 Q, 제라스 E,
    이즈리얼 Q, 레오나 E, 베이가 Q, 블리츠 Q, 쓰레쉬 Q, 징크스 W, 애쉬 R(점점 빨라짐).
    벨코즈 Q 는 내 옆을 지나갈 때(원래 길로는 빗나갈 때) 또는 사거리 끝에서 양옆 직각으로 갈라진다.
    갈라지기 0.25초 전(`SplitTelegraphTime`)에 구슬이 부풀며 번쩍인다. 롤처럼 갈라질 경로는 미리 안 보여 준다.
    갈라진 것은 속도 2100·반지름 45·사거리 1100(`VelkozQMissileSplit`)
  - 지연 장판 8개: 카서스 Q, 브랜드 W, 초가스 Q, 베이가 W, 신드라 Q, 제라스 W, 벨코즈 E, 레오나 R.
    바닥에 원이 보이고 다 차면 터진다
  - 지연 레이저 2개: 진 W, 럭스 R. 시전하는 동안 가는 선이 보이고 끝나는 순간 선 전체를 친다
  - 감옥 1개: 베이가 E. 테두리에 닿으면 맞는다
- 스킬 값의 출처: 롤 클라이언트의 챔피언 데이터 파일(CommunityDragon 의 `characters/*.bin.json`, 16.19).
  속도 `missileSpeed`, 반지름 `mLineWidth`, 사거리 `castRange`, 시전 시간 `mCastTime`(없으면 `spellCastTime`),
  장판 반지름 `castRadius`, 지연 시간 `CageDelay`·`ImpactDelay`·`DamageDelay` 등.
  데이터 파일에 없는 값(초가스·브랜드·카서스·신드라·레오나 장판의 지연 시간, 초가스 Q·럭스 R 시전 시간,
  베이가 E 지속 시간)은 롤 위키 값이다. `dodge.js` 의 표에 스킬마다 `src` 로 적어 두었다.
  신드라 Q 는 위키가 "누르고 0.6초 뒤 나타난다" 로 적어서 시전 시간을 0 으로 두었다(데이터의 spellCastTime 은 0.375)
- 표의 값은 데이터 파일에서 같은 항목을 읽어 한 줄씩 대조해 확인했다(16.19 기준, 108 항목 중 데이터에 있는 101 개 가운데 100 개가 같음.
  다른 1개는 위의 신드라 Q)
- 쏘는 사람은 롤에서처럼 사거리 끝 가까이(사거리의 60~100%)에서 쏜다
- 장판은 수치는 그대로 두고 찍는 자리만 사람처럼 한다. 정중앙에 찍으면 브랜드 W(반지름 240, 0.627초) 같은 건
  표시를 보자마자 달려도 못 나간다. 그래서 표시가 뜬 뒤 0.25초(반응 시간, `REACT`) 늦게 움직여도 딱 빠져나갈 만큼만
  내 자리에서 비껴 찍는다. 원은 여전히 몸에 걸쳐서 가만히 있으면 맞는다
- 스킬 판정과 내 판정 원이 겹치면 맞는다. 빠른 투사체가 한 프레임에 뛰어넘지 않게 1/240초씩 나눠 움직인다
- 규칙이 바뀌면 `dodge.js` 의 `VERSION` 과 `ranking.py` 의 `DODGE_VERSION` 을 같이 올린다.
  순위는 같은 버전의 기록끼리만 매기고, 예전 화면에서 온 기록은 받지 않는다
- 조작: 우클릭(누른 채 끌면 따라감), WASD·방향키, 휴대폰은 터치.
  WASD 는 `e.code` 로 읽어서 한글 입력 상태에서도 된다
- 기록: 판을 시작할 때 서버가 표를 끊고(`/api/dodge/start`), 끝났을 때 그 사이에 흐른 시간보다
  긴 기록은 받지 않는다(`ranking.py`). 1초 미만 판은 저장하지 않는다

## 로그인

Riot ID(이름#태그) + 이 사이트 전용 비밀번호. 가입할 때 OP.GG 에서 그 계정이
정말 있는지 확인한다. 한국 서버만 된다.

Riot 공식 로그인(RSO)은 Riot 의 정식(프로덕션) 앱 승인을 받아야 쓸 수 있다.
승인을 받으면 `auth.py` 의 `check_login` 자리만 바꾸면 된다.

### 닉네임(태그)을 바꾸면

계정은 puuid(라이엇 계정 고유 번호, 이름을 바꿔도 그대로) 로 묶여 있다.

- **새 닉네임으로 로그인**하면 OP.GG 에서 새 닉네임의 puuid 를 받아, 그 puuid 계정의 비밀번호와 맞춰 본다.
  맞으면 "옛 닉 → 새 닉, 이름이 변경되었습니까?" 를 묻고, 예를 누르면 계정 이름만 바꾼다. 전적과 그룹방은 그대로다
- 티어표·그룹방·듀오는 부를 때마다 저장된 puuid 와 OP.GG 의 puuid 를 맞춰 본다.
  다르면(누가 옛 닉네임을 가져갔으면) 남의 전적 대신 "닉네임이 바뀐 것 같아요" 를 보여 준다
- 대소문자만 바뀐 경우는 로그인할 때 OP.GG 표기대로 조용히 고친다

## 점수 매기는 법 (`perf.py`, `tierlist.py`)

재료는 최근 20판(솔로랭크·자유랭크·일반). 칼바람·아레나, 5분 안에 끝난 다시하기 판은 뺀다.
20판 승률은 팀운에 크게 흔들려서, 중심은 **판마다 얼마나 잘했나(플레이 점수)** 다.

### 플레이 점수 (한 판, 0~100, 50 = 보통)

지표마다 **그 라인의 보통 수준**과 견준다. 기준값은 에메랄드 평균 어림값이고,
그 판의 평균 티어에 맞춰 늘리고 줄인다(브론즈 판이면 CS 기준이 낮아진다).

| 영역 | 보는 것 |
|---|---|
| 전투 | KDA, 킬 관여율 |
| 성장 | 분당 CS, 팀 골드 중 내 몫 (서폿은 골드 몫만) |
| 스노우볼 | 14분 무렵 OP.GG 평점, 최다 연속 킬 |
| 딜 | 분당 챔피언 피해량 |
| 시야 | 분당 와드 설치 + 제어 와드 |
| OP.GG 평점 | OP.GG 가 매긴 그 판 평점(0~10) |

라인마다 비중이 다르다. 서폿은 시야·전투, 원딜은 딜·성장, 정글은 전투·스노우볼을 크게 본다.

### 챔피언 점수

점수 = 보정 플레이 점수 + 승률 보정 + 판수 가산 + 메타 가산

- **보정 플레이 점수**: 그 챔피언 판들의 플레이 점수 평균. 보통(50점) 판을 2판 섞어서
  1판만 잘한 챔피언이 꾸준히 잘한 챔피언을 앞지르지 않게 한다
- **승률 보정**: 50% 에서 10%p 벗어날 때마다 1점, 최대 ±5점
- **판수 가산**: 한 판 더 고를 때마다 0.75점 (8판까지)
- **메타 가산**: 내 티어 구간 OP.GG 챔피언 티어. 3티어 기준 한 칸에 1.5점

**실제 티어**는 솔로랭크 → 자유랭크 → (언랭이면) 최근 판들의 평균 티어 순서로 정한다.
공식 티어(메타 가산)와 플레이 점수 기준값 모두 이 티어 구간에 맞춘다.
그 구간의 공식 티어를 못 받으면 전체 구간 것을 쓰고, 화면에 "전체 구간" 이라고 적는다.

OP 는 1등 딱 한 명, 나머지는 점수 순서대로 1~5티어에 나눈다.

## 알아 둘 것

- 화면(`app.js` 의 `load`)은 한 번 받은 것을 기억해 두고, 화면을 옮겨도 다시 받지 않는다.
  로그인하면 내 티어표와 모든 방의 카드·주간 랭킹·무빙 순위를 뒤에서 미리 받아 둔다.
  새로 받는 건 새로고침하거나 "최신 전적으로" 버튼을 누를 때, 내가 바꾼 것(방 만들기·들어가기·나가기,
  스킬샷 기록)이 있을 때, 그리고 아래처럼 바뀐 게 보일 때뿐이다
- 바뀐 것만 다시 받기: 1분마다 `/api/stamp`(`changes.py`, DB 만 읽음)로 방 사람·무빙 기록·쌓인 경기 수의
  지문을 보고, 달라진 항목의 데이터만 다시 받는다. 5분마다는 받아 둔 티어표·방 카드·듀오를 다시 받아 새 판을 잡는다
  (서버가 OP.GG 대답을 10분 들고 있어서 OP.GG 를 매번 부르지는 않는다). 다른 탭에 있다 돌아오면 바로 한 번 본다.
  지금 보는 화면의 것이 바뀌었으면 로딩 없이 다시 그리고 알려 준다. 게임 중이거나 팝업을 보는 중이면 건드리지 않는다
- OP.GG MCP 서버는 원래 AI 도구용이다. 키는 없지만 너무 자주 부르지 않게
  받은 것을 `api_cache` 표에 잠깐 들고 있는다(전적 10분, 챔피언 통계 12시간).
- 처음 티어표를 만들 때는 챔피언마다 통계를 물어서 15초쯤 걸린다. 그다음부터는 바로 나온다.
- OP.GG 는 모드를 가리지 않고 한 번에 최근 20판만 알려 주고, 더 이전 판을 달라고 할 방법이 없다.
  그래서 받을 때마다 `match_rows` 에 쌓아 두고, 쌓인 것에서 협곡 판만 최근 20판을 꺼낸다.
  칼바람을 많이 하는 사람은 처음엔 20판이 안 찰 수 있고, 볼수록 채워진다.
  듀오 궁합도 쌓인 판 전부에서 같이 한 판을 찾으므로 자주 볼수록 정확해진다.

## 내 컴퓨터에서 돌리기

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

`http://127.0.0.1:8000` 으로 접속. 데이터는 `mytier.db` 파일에 쌓인다.

## 올리는 법 (Render, 무료)

1. <https://render.com> → **New** → **Web Service** → 이 저장소 고르기.
   `render.yaml` 이 있으니 설정은 자동으로 잡힌다.
2. **Environment** 에 `DATABASE_URL` 을 넣는다. 무료 요금제는 서버가 잠들었다 깨면
   파일이 날아가므로, 계정과 방은 바깥 Postgres(<https://neon.com> 무료)에 둔다.
3. Deploy.

무료 요금제는 15분 안 쓰면 잠들고, 다시 깨는 데 30초쯤 걸린다.
그래서 `.github/workflows/keepalive.yml` 이 10분마다 `/api/health` 를 불러 깨워 둔다.
- 무료 750시간/월은 서비스 하나를 계속 켜 두는 만큼(약 720시간)이다. 깨워 둘 서비스는 하나만 둔다
- 저장소에 60일 동안 변경이 없으면 GitHub 이 예약 실행을 멈춘다. 그땐 Actions 탭에서 다시 켠다

DB 는 연결을 몇 개 열어 두고 돌려 쓴다(`database.py` 의 연결 풀).
4분 넘게 안 쓴 연결은 닫아서 Neon 이 잠들 수 있게 한다.

### 주소(도메인)

- Render 주소(`이름.onrender.com`)는 서비스를 **만들 때** 이름으로 정해지고, 나중에 바꿀 수 없다.
  `render.yaml` 의 이름은 `tier-gg` 라서 새로 만들면 `tier-gg.onrender.com` 이 된다.
  예전 `woori-sosik.onrender.com` 서비스는 이름만 바꿔도 주소가 그대로다.
- `tier.gg` 같은 진짜 도메인은 따로 사서 Render 서비스의 **Settings → Custom Domains** 에 붙인다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.py` | API (로그인, 티어표, 그룹방, 듀오) |
| `opgg.py` | OP.GG 부르기, 대답 읽기, 잠깐 들고 있기 |

| `duo.py` | 듀오 궁합 |
| `ranking.py` | 스킬샷 피하기 기록, 그룹방 순위, 주간 랭킹 |
| `changes.py` | 바뀐 게 있는지 보는 지문(`/api/stamp`) |
| `auth.py` | 계정과 로그인. 비밀번호는 해시로 저장 |
| `database.py` | SQLite/Postgres 연결과 표 만들기 |
| `static/` | 화면 (`index.html`, `app.css`, `app.js`, 스킬샷 피하기 게임 `dodge.js`) |
